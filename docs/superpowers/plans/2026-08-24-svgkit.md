# svgkit Revival Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Reintroduce `@react-pdf/svgkit`: a pdfkit-shaped drawing context that `@react-pdf/render` drives unchanged, emitting one serialized `<svg>` string per page.

**Architecture:** `SVGDocument` implements the ~45 pdfkit methods render calls, building a tiny virtual element tree serialized at `end()`. Text crosses the ctx boundary through a new capability seam in render's `renderGlyphs.ts` (`ctx.glyphs?`); embedded fonts render as glyph-outline `<path>`s, standard (AFM) fonts fall back to `<text>` since they have no outlines. Forms/notes/bookmarks are silent no-op stubs.

**Tech Stack:** TypeScript, Rollup (same skeleton as `packages/image`), Vitest string snapshots. Zero runtime dependencies.

**Spec:** `docs/superpowers/specs/2026-08-24-svgkit-design.md`

---

## Context you need before starting

- `render(ctx, doc)` (`packages/render/src/index.ts`) drives any ctx; it calls `ctx.end()` itself.
- The full ctx surface render can touch is enumerated in `packages/render/tests/ctx.ts` (a vi.fn mock). svgkit must implement or stub everything in that file, **all chainable** (`return this`) — render chains calls like `ctx.fillOpacity(o).image(...)` and `ctx.save().translate(...)`.
- Coordinate system: render works y-down top-left (pdfkit style). SVG is natively y-down — no global flip. Glyph outlines are y-up, so each glyph gets a local `scale(s, -s)`.
- Textkit `Position.xAdvance` is in points. `renderGlyphs.ts` scales offsets by `fontSize / 1000` before emitting PDF — svgkit replicates that exact math (`xOffset * fontSize / 1000`) so SVG matches PDF output, quirks included.
- `StandardFont` glyphs (`packages/font/src/standard-font.ts`) have **no `.path`** — only `{ id, codePoints, name, advanceWidth }`. That's why the `<text>` fallback exists. Embedded fontkit glyphs have `.path` with a `.toSVG()` method.
- `vitest.workspace.js` already lists `packages/svgkit` — no change needed there.
- Node 18 breaks `yarn install`; if installing, use the nvm v22 path first.

```ts
// packages/svgkit/src/element.ts
export type SVGElementNode = {
  name: string;
  attributes: Record<string, string | number>;
  children: (SVGElementNode | string)[];
};

export const createElement = (name: string): SVGElementNode => ({
  name,
  attributes: {},
  children: [],
});

export const setAttribute = (
  element: SVGElementNode,
  name: string,
  value: string | number,
) => {
  element.attributes[name] = value;
};

export const appendChild = (
  parent: SVGElementNode,
  child: SVGElementNode | string,
) => {
  parent.children.push(child);
};

export const fmt = (value: number) => {
  const rounded = Math.round(value * 1e4) / 1e4;
  return Object.is(rounded, -0) ? 0 : rounded;
};
```

```ts
// packages/svgkit/src/serialize.ts
import { SVGElementNode } from './element';

const escapeAttribute = (value: string) =>
  value.replace(/&/g, '&amp;').replace(/</g, '&lt;').replace(/"/g, '&quot;');

const escapeText = (value: string) =>
  value.replace(/&/g, '&amp;').replace(/</g, '&lt;').replace(/>/g, '&gt;');

const serialize = (element: SVGElementNode): string => {
  const attributes = Object.entries(element.attributes)
    .map(([name, value]) => ` ${name}="${escapeAttribute(String(value))}"`)
    .join('');

  if (element.children.length === 0)
    return `<${element.name}${attributes}/>`;

  const children = element.children
    .map((child) =>
      typeof child === 'string' ? escapeText(child) : serialize(child),
    )
    .join('');

  return `<${element.name}${attributes}>${children}</${element.name}>`;
};

export default serialize;
```

### Task 3: Document core — pages, graphics-state stack, transforms

The state model: `save()` snapshots `{ container, style }` onto a stack; `restore()` pops it. Every transform call opens a nested `<g transform>` that becomes the current container (appending to an existing group's `transform` attribute would retroactively move already-emitted children). Style (colors, opacities, line attrs, dash) lives in a mutable object copied on save. Font state (`_font`, `_fontSize`) is deliberately **outside** the stack — pdfkit's q/Q doesn't cover text state either, and render re-sets the font before every run.

```ts
// packages/svgkit/src/document.ts
import {
  SVGElementNode,
  appendChild,
  createElement,
  fmt,
  setAttribute,
} from './element';
import serialize from './serialize';

export type SVGDocumentOptions = {
  /** Prepended to generated ids so multiple documents can coexist in one DOM */
  idPrefix?: string;
};

type Style = {
  fillColor: string;
  strokeColor: string;
  fillOpacity: number;
  strokeOpacity: number;
  opacity: number;
  lineWidth: number;
  lineCap: string | null;
  lineJoin: string | null;
  miterLimit: number | null;
  dashArray: string | null;
  dashPhase: number | null;
};

const defaultStyle = (): Style => ({
  fillColor: 'black',
  strokeColor: 'black',
  fillOpacity: 1,
  strokeOpacity: 1,
  opacity: 1,
  lineWidth: 1,
  lineCap: null,
  lineJoin: null,
  miterLimit: null,
  dashArray: null,
  dashPhase: null,
});

const makeOutline = () => {
  const outline: any = {};
  outline.addItem = () => outline;
  return outline;
};

class SVGDocument {
  pages: string[] = [];
  page = { width: 0, height: 0, annotations: [] as any[], fonts: {} as any };
  info: Record<string, any> = {};
  outline = makeOutline();
  _root = { data: {} as any };
  _imageRegistry: Record<string, any> = {};
  _font: any = null;
  _fontSize = 12;

  protected idPrefix: string;
  protected idCounter = 0;
  protected roots: SVGElementNode[] = [];
  protected container!: SVGElementNode;
  protected defs!: SVGElementNode;
  protected style: Style = defaultStyle();
  protected stack: { container: SVGElementNode; style: Style }[] = [];
  protected currentPath = '';

  constructor(options: SVGDocumentOptions = {}) {
    this.idPrefix = options.idPrefix ?? '';
  }

  addPage(options: { size?: number[] } = {}) {
    const [width, height] = options.size ?? [612, 792];

    const svg = createElement('svg');
    setAttribute(svg, 'xmlns', 'http://www.w3.org/2000/svg');
    setAttribute(svg, 'viewBox', `0 0 ${fmt(width)} ${fmt(height)}`);
    setAttribute(svg, 'width', fmt(width));
    setAttribute(svg, 'height', fmt(height));

    this.defs = createElement('defs');
    appendChild(svg, this.defs);

    this.roots.push(svg);
    this.container = svg;
    this.stack = [];
    this.style = defaultStyle();
    this.currentPath = '';
    this.page = { width, height, annotations: [], fonts: {} };

    return this;
  }

  end() {
    this.pages = this.roots.map(serialize);
    return this;
  }

  save() {
    this.stack.push({ container: this.container, style: { ...this.style } });
    return this;
  }

  restore() {
    const entry = this.stack.pop();
    if (entry) {
      this.container = entry.container;
      this.style = entry.style;
    }
    return this;
  }

  protected openGroup(attributes: Record<string, string | number>) {
    const group = createElement('g');
    Object.entries(attributes).forEach(([name, value]) =>
      setAttribute(group, name, value),
    );
    appendChild(this.container, group);
    this.container = group;
    return this;
  }

  protected nextId(kind: string) {
    this.idCounter += 1;
    return `${this.idPrefix}${kind}-${this.idCounter}`;
  }

  transform(a: number, b: number, c: number, d: number, e: number, f: number) {
    return this.openGroup({
      transform: `matrix(${fmt(a)} ${fmt(b)} ${fmt(c)} ${fmt(d)} ${fmt(e)} ${fmt(f)})`,
    });
  }

  translate(x: number, y: number, _options?: any) {
    return this.openGroup({ transform: `translate(${fmt(x)} ${fmt(y)})` });
  }

  rotate(angle: number, options: { origin?: number[] } = {}) {
    const origin = options.origin
      ? ` ${fmt(options.origin[0])} ${fmt(options.origin[1])}`
      : '';
    return this.openGroup({ transform: `rotate(${fmt(angle)}${origin})` });
  }

  scale(sx: number, sy?: number | object, options: { origin?: number[] } = {}) {
    if (typeof sy === 'object') {
      options = sy as { origin?: number[] };
      sy = sx;
    }
    const yFactor = sy == null ? sx : (sy as number);
    const scale = `scale(${fmt(sx)} ${fmt(yFactor)})`;
    const transform = options.origin
      ? `translate(${fmt(options.origin[0])} ${fmt(options.origin[1])}) ${scale} translate(${fmt(-options.origin[0])} ${fmt(-options.origin[1])})`
      : scale;
    return this.openGroup({ transform });
  }
}

export default SVGDocument;
```

```ts
describe('paths', () => {
  test('curves accumulate into one path', () => {
    const doc = makeDoc();
    doc
      .moveTo(0, 0)
      .lineTo(10, 0)
      .bezierCurveTo(11, 1, 12, 2, 13, 3)
      .quadraticCurveTo(14, 4, 15, 5)
      .closePath()
      .stroke();
    expect(pageContent(doc)).toBe(
      '<defs/><path d="M0 0L10 0C11 1 12 2 13 3Q14 4 15 5Z" fill="none" stroke="black" stroke-width="1"/>',

    const doc = makeDoc();

    doc.rect(1, 2, 3, 4).fill();
    doc.stroke(); // no path accumulated → no element
```

```ts
class SVGGradient {
  id: string;
  emitted = false;

  private kind: 'linearGradient' | 'radialGradient';
  private attributes: Record<string, number>;
  private stops: Stop[] = [];

  constructor(
    id: string,
    kind: 'linearGradient' | 'radialGradient',
    attributes: Record<string, number>,
  ) {
    this.id = id;
    this.kind = kind;
    this.attributes = attributes;

  }

  toElement(): SVGElementNode {
    const el = createElement(this.kind);
    setAttribute(el, 'id', this.id);
    setAttribute(el, 'gradientUnits', 'userSpaceOnUse');
    Object.entries(this.attributes).forEach(([name, value]) =>

      setAttribute(stop, 'stop-color', color);
```

```ts
// packages/svgkit/src/image.ts
const BASE64 =
  'ABCDEFGHIJKLMNOPQRSTUVWXYZabcdefghijklmnopqrstuvwxyz0123456789+/';

const toBase64 = (bytes: Uint8Array) => {
  let out = '';
  for (let i = 0; i < bytes.length; i += 3) {
    const a = bytes[i];
    const b = bytes[i + 1] ?? 0;
    const c = bytes[i + 2] ?? 0;
    out += BASE64[a >> 2];
    out += BASE64[((a & 3) << 4) | (b >> 4)];
    out += i + 1 < bytes.length ? BASE64[((b & 15) << 2) | (c >> 6)] : '=';
    out += i + 2 < bytes.length ? BASE64[c & 63] : '=';
  }
  return out;
};

const asBytes = (data: any): Uint8Array | null => {
  if (data instanceof Uint8Array) return data;
  if (data instanceof ArrayBuffer) return new Uint8Array(data);
  return null;
};

const isPng = (bytes: Uint8Array) =>
  bytes[0] === 0x89 && bytes[1] === 0x50 && bytes[2] === 0x4e;

const isJpeg = (bytes: Uint8Array) => bytes[0] === 0xff && bytes[1] === 0xd8;

export const toHref = (data: any): string => {
  if (typeof data === 'string') return data;
  const bytes = asBytes(data);
  if (!bytes) return '';
  const mime = isPng(bytes) ? 'image/png' : 'image/jpeg';
  return `data:${mime};base64,${toBase64(bytes)}`;
};

const readUInt32BE = (bytes: Uint8Array, offset: number) =>
  (bytes[offset] << 24) | (bytes[offset + 1] << 16) | (bytes[offset + 2] << 8) | bytes[offset + 3];

const readUInt16BE = (bytes: Uint8Array, offset: number) =>
  (bytes[offset] << 8) | bytes[offset + 1];

export const imageDimensions = (
  data: any,
): { width: number; height: number } | null => {
  const bytes = asBytes(data);
  if (!bytes) return null;

  if (isPng(bytes)) {
    return {
      width: readUInt32BE(bytes, 16) >>> 0,
      height: readUInt32BE(bytes, 20) >>> 0,
    };
  }

  if (isJpeg(bytes)) {
    let offset = 2;
    while (offset < bytes.length - 8) {
      if (bytes[offset] !== 0xff) break;
      const marker = bytes[offset + 1];
      // SOF0-SOF15, excluding DHT/DAC/RST
      if (marker >= 0xc0 && marker <= 0xcf && ![0xc4, 0xc8, 0xcc].includes(marker)) {
        return {
          height: readUInt16BE(bytes, offset + 5),
          width: readUInt16BE(bytes, offset + 7),
        };
      }
      offset += 2 + readUInt16BE(bytes, offset + 2);
    }
  }

  return null;
};
```

```ts
const STANDARD_FAMILIES: Record<string, string> = {
  Helvetica: 'Helvetica, Arial, sans-serif',
  Courier: '"Courier New", Courier, monospace',
  Times: '"Times New Roman", Times, serif',

export type FontFace = {
  family: string;
  bold: boolean;
  italic: boolean;
};

export const resolveFontFace = (font: any): FontFace => {
  const name: string =
    typeof font === 'string' ? font : (font?.fullName ?? font?.postscriptName ?? '');
  const base = name.split('-')[0];
  return {
    family: STANDARD_FAMILIES[base] ?? (name || 'sans-serif'),
    bold: /Bold/.test(name),
    italic: /Italic|Oblique/.test(name),
  };
};

export const unitsPerEmOf = (font: any) =>
  (typeof font === 'object' && font?.unitsPerEm) || 1000;
```

```ts
    this._font = src;
    if (typeof size === 'number') this._fontSize = size;
    return this;

  fontSize(size: number) {
    this._fontSize = size;

  protected applyTextFont(el: SVGElementNode) {
    const face = resolveFontFace(this._font);
    setAttribute(el, 'font-family', face.family);
    setAttribute(el, 'font-size', fmt(this._fontSize));
    if (face.bold) setAttribute(el, 'font-weight', 'bold');
    if (face.italic) setAttribute(el, 'font-style', 'italic');
  }

  glyphs(glyphs: any[], positions: any[], x: number, y: number) {
    if (glyphs.length === 0) return this;

    const fontSize = this._fontSize;
    // Same offset scaling renderGlyphs.ts applies on the PDF side; divergence
    // would only show for OpenType mark positioning.
    const offsetScale = fontSize / 1000;

    if (!glyphs[0].path) return this.glyphsAsText(glyphs, positions, x, y, offsetScale);

    const scale = fontSize / unitsPerEmOf(this._font);
    const group = createElement('g');
    setAttribute(group, 'fill', this.resolvePaint(this.style.fillColor));
    const fillOpacity = this.style.fillOpacity * this.style.opacity;
    if (fillOpacity !== 1) setAttribute(group, 'fill-opacity', fmt(fillOpacity));

    let pen = x;
    for (let i = 0; i < glyphs.length; i += 1) {
      const pos = positions[i];
      const d = glyphs[i].path?.toSVG();
      if (d) {
        const gx = pen + (pos.xOffset || 0) * offsetScale;
        const gy = y - (pos.yOffset || 0) * offsetScale;
        const el = createElement('path');
        setAttribute(el, 'd', d);
        setAttribute(el, 'transform', `translate(${fmt(gx)} ${fmt(gy)}) scale(${fmt(scale)} ${fmt(-scale)})`);
        appendChild(group, el);
      }
      pen += pos.xAdvance || 0;
    }

    appendChild(this.container, group);
    return this;
  }

  protected glyphsAsText(
    glyphs: any[],
    positions: any[],
    x: number,
    y: number,
    offsetScale: number,
  ) {
    const xs: (string | number)[] = [];
    let text = '';
    let pen = x;

    for (let i = 0; i < glyphs.length; i += 1) {
      const codePoints: number[] = glyphs[i].codePoints ?? [];
      // ponytail: multi-codepoint glyphs share one x; fine for the standard 14
      text += String.fromCodePoint(...codePoints);
      const gx = pen + (positions[i].xOffset || 0) * offsetScale;
      codePoints.forEach(() => xs.push(fmt(gx)));
      pen += positions[i].xAdvance || 0;
    }

    const el = createElement('text');
    setAttribute(el, 'x', xs.join(' '));
    setAttribute(el, 'y', fmt(y));
    this.applyTextFont(el);
    setAttribute(el, 'fill', this.resolvePaint(this.style.fillColor));
    const fillOpacity = this.style.fillOpacity * this.style.opacity;
    if (fillOpacity !== 1) setAttribute(el, 'fill-opacity', fmt(fillOpacity));
    setAttribute(el, 'xml:space', 'preserve');
    appendChild(el, text);
    appendChild(this.container, el);
    return this;
  }

  text(value: string, x = 0, y = 0, _options?: any) {
    const el = createElement('text');
    setAttribute(el, 'x', fmt(x));
    setAttribute(el, 'y', fmt(y));
    this.applyTextFont(el);
    setAttribute(el, 'fill', this.resolvePaint(this.style.fillColor));
    setAttribute(el, 'xml:space', 'preserve');
    appendChild(el, value);
    appendChild(this.container, el);
    return this;
  }
```

```markdown
# @react-pdf/svgkit

pdfkit-compatible drawing context that renders react-pdf documents to SVG
strings instead of PDF. Useful for lightweight in-browser previews (REPL,
doc site) without pdfkit or pdf.js.

## Usage

\`\`\`js
import FontStore from '@react-pdf/font';
import layout from '@react-pdf/layout';
import render from '@react-pdf/render';
import SVGDocument from '@react-pdf/svgkit';

const fontStore = new FontStore();
const resolved = await layout(documentTree, fontStore);

const ctx = new SVGDocument({ idPrefix: 'doc1-' });
render(ctx, resolved); // render calls ctx.end() itself

ctx.pages; // string[] — one `<svg>…</svg>` per page
\`\`\`

Pass `idPrefix` when several documents share one DOM so clip/gradient ids
don't collide.

## Text

Registered (embedded) fonts render as glyph-outline `<path>` elements —
pixel-faithful to the PDF output, not selectable. The standard 14 PDF fonts
(Helvetica, Times, Courier) have no outline data, so they render as `<text>`
elements with per-glyph positioning and CSS font fallbacks; exact shapes
then depend on the viewer's installed fonts.

## Parity exceptions

These pdfkit features are silent no-ops in SVG output: form fields
(TextInput, Select, Checkbox…), notes/annotations, bookmarks/outlines.
Links (`src`) and internal destinations (`id`/`#dest`) are supported.
```
